ASHA working status CSV rule

The second file contains the current working and payment status for ASHA workers.

CSV rule for payment status

Each row represents one ASHA worker, one month and one payment head.

Use this exact header: asha_id,month,head,claimed_amount,approved_amount,stage,stage_date

month must be an English month name, amounts must be whole numbers, and stage must be anm_pending, moic_pending, bam_pending or paid. These mean ANM voucher pending, MOIC approval pending, BAM payment pending and payment complete. Use YYYY-MM-DD for the date.
