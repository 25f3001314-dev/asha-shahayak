CSV rule for payment status

Each row represents one ASHA worker, one month and one payment head.

In simple words: one line = one payment of one ASHA for one month. If an ASHA has 3 payments, she gets 3 lines.

Use this exact header as the first line of the file. Do not change it or add columns: asha_id,month,head,claimed_amount,approved_amount,stage,stage_date

What to write in each column

ColumnWhat to writeExample
asha_idThe ASHA's IDASHA-106
monthMonth name in Englishmarch
headWhich work the payment is for. The chatbot knows: vaccination, home_visit, institutional_delivery, family_planningvaccination
claimed_amountAmount the ASHA claimed, in rupees. Whole number only (no ₹ sign, no comma)300
approved_amountAmount approved, in rupees. Whole number only300
stageWhere the payment is right now. Choose one from the list belowpaid
stage_dateDate of that stage, written as YYYY-MM-DD2026-03-28

Which stage to choose

Write thisMeaningWhat the ASHA hears from the chatbot
anm_pendingANM voucher pendingHer voucher is still with the ANM
moic_pendingMOIC approval pendingApproval is still pending with the MOIC
bam_pendingBAM payment pending (approved, money not yet released)Amount is approved, payment from the block is awaited
paidPayment completeThe money has been received

Before you upload

  • Save the file as CSV (in Excel: Save As, then CSV UTF-8).
  • Write month and stage exactly as shown, in small letters.
  • Every ASHA ID in this file should also be in the registry file. IDs missing from the registry show "No" in the table below, and the chatbot will not find them.

asha_id,month,head,claimed_amount,approved_amount,stage,stage_date
